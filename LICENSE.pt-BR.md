## Prefácio

A Licença Geral Pública GNU é uma licença livre e *copyleft* para software e outros tipos de trabalhos.

As licenças para a maioria dos softwares e outros trabalhos práticos são projetadas para retirar de você a liberdade de compartilhar e modificar as obras. Em contraste, a Licença Geral Pública GNU tem por objetivo garantir a sua liberdade de compartilhar e modificar todas as versões de um programa — garantindo que ele permaneça como software livre para todos os seus usuários. Nós, a Free Software Foundation, utilizamos a Licença Geral Pública GNU para a maior parte dos nossos softwares; ela se aplica também a qualquer outro trabalho distribuído dessa forma por seus autores. Você também pode aplicá-la aos seus programas.

Quando falamos em software livre, estamos nos referindo à liberdade, e não ao preço. Nossas Licenças Gerais Públicas foram projetadas para garantir que você tenha a liberdade de distribuir cópias de software livre (e cobrar por elas, se desejar), que você receba o código-fonte ou possa obtê-lo se quiser, que você possa modificar o software ou usar partes dele em novos programas livres e que você saiba que pode fazer essas coisas.

Para proteger os seus direitos, precisamos impedir que outros neguem a você esses direitos ou peçam que você renuncie a eles. Portanto, você tem certas responsabilidades se distribuir cópias do software, ou se modificá-lo: responsabilidades de respeitar a liberdade dos outros.

Por exemplo, se você distribuir cópias de tal programa, seja gratuitamente ou por uma taxa, deve repassar aos destinatários as mesmas liberdades que recebeu. Você deve garantir que eles também recebam ou possam obter o código-fonte. E deve mostrar a eles estes termos para que conheçam seus direitos.

Os desenvolvedores que usam a GNU GPL protegem seus direitos com dois passos: (1) afirmam o direito autoral sobre o software e (2) oferecem a você esta Licença, dando-lhe permissão legal para copiar, distribuir e/ou modificar o software.

Para a proteção dos desenvolvedores e dos autores, a GPL deixa claro que não há garantia para este software livre. Tanto por causa dos usuários quanto dos autores, a GPL exige que as versões modificadas sejam marcadas como alteradas, para que seus problemas não sejam atribuídos incorretamente aos autores de versões anteriores.

Alguns dispositivos são projetados para negar aos usuários a possibilidade de instalar ou executar versões modificadas do software neles, embora o fabricante possa fazê-lo. Isso é fundamentalmente incompatível com o objetivo de proteger a liberdade dos usuários de modificar o software. O padrão sistemático de tal abuso ocorre na área de produtos para uso individual, que é exatamente onde é mais inaceitável. Portanto, projetamos esta versão da GPL para proibir essa prática nesses produtos. Se tais problemas surgirem substancialmente em outros domínios, estamos prontos para estender esta disposição a esses domínios em versões futuras da GPL, conforme necessário para proteger a liberdade dos usuários.

Finalmente, todo programa é ameaçado constantemente por patentes de software. O Código-fonte Correspondente não precisa incluir nada que os usuários possam regenerar automaticamente a partir de outras partes do Código-fonte Correspondente.

O Código-fonte Correspondente para uma obra em forma de código-fonte é essa mesma obra.
